KUASAI KONVERSI STRING & NUMBER!

Pelajari bedanya teks "10" dengan angka 10, cara menggunakan fungsi Number(), dan mencegah perangkap gabungan teks saat membuat aplikasi Kasir dan Kalkulator!

Pochita Approved

"Hati-hati! Tanpa Number(), prompt() akan menggabungkan teks, bukan menghitung angka!"

Tipe Data String

Diapit petik "10". Tanda + pada String berfungsi untuk **menggabungkan teks** (Concatenation).

Tipe Data Number

Angka murni tanpa petik 10. Tanda + pada Number berfungsi untuk **penjumlahan matematika**.

Fungsi Number()

Mengubah String menjadi Number. Sangat wajib dipakai saat membaca hasil dari prompt().
