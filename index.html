1. Pengertian Variabel & Analogi

Dalam dunia pemrograman, Variabel adalah nama tempat di memori komputer yang digunakan untuk **menyimpan data**. Data ini nantinya dapat kita baca, diubah, atau dihitung oleh script JavaScript kita.

📦

Analogi Wadah / Kotak

Bayangkan variabel seperti kotak penyimpanan. Anda bisa memasukkan barang (data) ke dalamnya dan mengambilnya sewaktu-waktu.

🏷️

Label / Nama Variabel

Setiap kotak diberi nama unik (seperti namaKarakter atau jumlahDarah) agar program tahu kotak mana yang dipanggil.

🥩

Isi / Nilai Data

Isi di dalam kotak bisa berupa teks ("Denji"), angka (100), status boolean (true), atau data rumit lainnya.

2. Cara Deklarasi: var, let, dan const

Tabel Perbedaan Deklarasi Variabel

Keyword Tipe Scope Bisa Diubah Nilainya? (Re-assign) Bisa Dideklarasi Ulang? Perilaku Hoisting
var Function Scope ✅ Ya ✅ Ya Di-hoist (Nilai: undefined)
let Block Scope { } ✅ Ya ❌ Tidak TDZ (Temporal Dead Zone)
const Block Scope { } ❌ Tidak (Tetap/Konstan) ❌ Tidak TDZ (Temporal Dead Zone)

Mengenal Block Scope vs Function Scope

- Block Scope { }: Variabel let & const hanya hidup di dalam kurung kurawal `{ }` tempat dia dibuat. Di luar kurung kurawal, variabel tersebut **tidak dapat diakses**.

- Function Scope: Variabel var menembus kurung kurawal biasa (seperti if atau for), tetapi terkurung di dalam fungsi.

Apa itu Hoisting & TDZ?

JavaScript akan membaca dan mengangkat (hoist) semua deklarasi variabel ke bagian paling atas kode sebelum mengeksekusinya.

// VAR: menghasilkan undefined jika dipanggil sebelum deklarasi

console.log(b); // output: undefined

var b = "Denji";

3. Aturan Penulisan Nama Variabel

Aturan Wajib Karakter

  • ✓ Dapat diawali dengan huruf (a-z, A-Z), garis bawah (_), atau tanda dollar ($).
  • ✗ DILARANG diawali dengan angka! (Contoh salah: 1denji).
  • ✗ Tidak boleh memakai spasi atau karakter khusus seperti @-#!%.
  • ! Bersifat Case-Sensitive: darah dan Darah adalah dua variabel yang berbeda.
  • ✗ Tidak boleh memakai kata kunci resmi JavaScript (Reserved Keywords) seperti function, return, class, let, const, if.

Gaya Penulisan (Naming Conventions)

camelCase (Standar Utama JavaScript)

Kata pertama huruf kecil, kata selanjutnya diawali huruf kapital.

let namaPemburuIblis = "Denji";
snake_case

Menggunakan garis bawah untuk memisahkan antar kata.

let jumlah_darah = 100;
PascalCase

Setiap kata diawali dengan huruf kapital (biasanya untuk nama Class).

class DevilHunter { ... }

4. Tipe Data Lengkap di JavaScript

Tipe Data Primitif (Nilai Tunggal)

1. Number

Menyimpan angka bulat, desimal, hingga nilai khusus (NaN & Infinity).

let hp = 100; let score = 98.5;
2. String

Teks dalam tanda petik tunggal, ganda, atau Template Literals backtick (` `).

let nama = "Denji"; let s = `Hero: ${nama}`;
3. Boolean

Nilai kebenaran: hanya true (benar) atau false (salah).

let isDevilHybrid = true;
4. Null vs Undefined

Null = Nilai sengaja dikosongkan. Undefined = Variabel sudah dibuat tapi belum ada isinya.

let kontr = null; let power; // undefined
5. BigInt & Symbol

BigInt untuk angka sangat raksasa, Symbol untuk identifier unik.

let big = 9007199254740991n;

Tipe Data Non-Primitif (Kompleks)

Object

Kumpulan data dengan pasangan nama properti dan nilainya.

let denji = { role: "Devil Hunter", hp: 100 };
Array

Daftar sekumpulan data yang tersusun berurutan berdasarkan indeks.

let senjata = ["Chainsaw", "Axe", "Blood"];

Dynamic Typing & Operator typeof

JavaScript bersifat Dynamically Typed. Artinya, tipe data variabel disesuaikan secara otomatis berdasarkan nilai yang sedang dimasukkan saat itu. Kita dapat mengecek tipe data menggunakan perintah typeof.

let data = 100; // typeof data -> "number"

data = "Denji"; // typeof data -> "string"

5. Mengenal console.log() & Cara Output Data

Perintah console.log() adalah alat utama developer untuk menampilkan pesan, isi nilai variabel, atau hasil perhitungan ke dalam terminal/console browser.

1. Output Multiple Values

Gunakan koma , untuk menampilkan banyak nilai sekaligus.

console.log("Hero:", nama, hp);

2. String Interpolation

Gunakan backtick ` ` dan ${...} untuk menyisipkan variabel.

console.log(`HP Denji: ${hp}`);

3. Evaluasi Ekspresi

Bisa langsung menghitung matematika atau logika di dalam log.

console.log("Total:", 100 - 25);

6. Mengenal Error: Error Bukan Berarti Gagal!

💡

Pesan Penting untuk Programmer Pemula:

Jangan panik jika menemukan warna merah/Error di console! Error dalam JavaScript bukanlah bukti bahwa Anda gagal, melainkan **petunjuk ramah dari browser** yang memberitahu baris mana yang perlu diperbaiki.

TypeError

Kesalahan Tipe / Assignment

Terjadi saat kita mencoba mengubah nilai variabel const yang sifatnya tetap.

const hero = "Denji";
hero = "Pochita"; // ❌ TypeError!
ReferenceError

Variabel Tidak Ditemukan

Terjadi saat kita memanggil variabel yang belum pernah dibuat atau dipanggil sebelum inisialisasi (let/const).

console.log(power); // ❌ ReferenceError!
let power = 100;
SyntaxError

Kesalahan Aturan Penulisan

Terjadi jika nama variabel melanggar aturan (misal: diawali angka) atau variabel let/const dideklarasikan dua kali.

let 1denji = "Salah"; // ❌ SyntaxError!
